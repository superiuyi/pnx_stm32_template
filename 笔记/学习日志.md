# 11.16 学习日志

1. BMI088 的原理
    - 为什么需要 BMI088？
      机器人需要姿态、角速度、加速度；单靠一个传感器不够，要融合。
    - 如何更准确地得到角度和加速度？
      角度：陀螺 + 加速度计 + 磁力计融合（ESKF）。
      加速度：加速度计测的是比力，先用姿态把重力减掉。
    - 如何规避 YAW 问题？
      6 轴 yaw 不可观测，会漂；要靠磁力计/视觉等外部参考。
      当前 BMI088 的 yaw 只能当相对角度。

2. OLED 线程：从不亮到跑通
    - 理解了 CubeMX 的 "Do not generate the main()"：
      main 由 wrapper 手写，初始化顺序更清楚；
      代价是新增外设要自己调用 MX_*_Init()。
    - 问题：驱动里把 hi2c2 写成了 hi2c3。
      C 板 OLED 口是 I2C2，I2C3 接的是 IST8310。
    - 还有：init.cpp 漏了 MX_I2C2_Init()。
    - 修复：启用 I2C2，调用 MX_I2C2_Init()，驱动改回 hi2c2。

3. C++ 链接器的原理
    - 头文件相当于直接复制到源文件里，所以头文件里不要随便写定义。
    - 先声明，再定义：
      声明让编译器知道类型，定义让链接器找到符号。
      声明有参数时要带参数类型，参数名可省。
      同时声明有参数和无参数版本，就是重载。
    - thread.cpp：
      ```cpp
      void led_start();
      void oled_start();

      extern "C" void app_start()
      {
          led_start();
          oled_start();
      }
      ```
      app_start 要给 BSP/ThreadX 按 C 符号调用，所以加 extern "C"；
      led_start / oled_start 只在 C++ 内部调用，不用加。
    - static：文件作用域是内部链接，只在本文件可见；不是完全不参与链接。
    - extern "C"：按 C 规则链接，避免 C++ 改名；C/C++ 混用时用。
